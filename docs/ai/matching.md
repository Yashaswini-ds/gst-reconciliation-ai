# AI Matching & Discrepancy Specification (M7.1)

## 1. Role of AI in Reconciliation Pipeline

AI functions strictly as an **intelligence assistance layer** in the 10-step reconciliation pipeline.

```text
 1. Normalization (Deterministic)
 2. Candidate Generation (Deterministic)
 3. Exact Candidate Search (Deterministic)
 4. Fuzzy Candidate Search (Deterministic)
 5. AI Candidate Ambiguity Evaluation (AI Gateway - Assistance Only)
 6. Field-by-Field Comparison (Deterministic Engine)
 7. Rule & Tolerance Check (Deterministic Engine)
 8. Primary Classification (Deterministic Engine Authority)
 9. AI Discrepancy Review (AI Gateway - Explanation Only)
10. Manual Review Routing (Deterministic Workflow Flag)
```

---

## 2. AI Tasks & Boundaries

### 2.1 Task 1: AI Schema Mapping
- **Input**: List of unmapped source file column headers.
- **Output**: JSON map suggestions to canonical schema fields.
- **Boundary**: Suggestions must strictly belong to the canonical field schema (`invoice_number`, `gstin`, `invoice_date`, `taxable_value`, `cgst`, `sgst`, `igst`, `total_invoice_value`). Alias dictionary rules take precedence.

### 2.2 Task 2: AI Candidate Ambiguity Resolution
- **Input**: Target GST record + pre-filtered candidate ERP records generated by `CandidateGenerator`.
- **Output**: Selected candidate identifier, confidence score, evidence list, reasoning.
- **Boundary**: AI cannot generate candidates outside the supplied list. AI cannot compute numeric differences or evaluate monetary tolerances. If confidence < 0.95, the system flags `requires_manual_review = True`.

### 2.3 Task 3: Post-Reconciliation AI Discrepancy Review
- **Input**: Pre-computed `ReconciliationRecordResult` containing `field_differences`.
- **Output**: Human-readable explanation, AI remark, audit remark, recommended action.
- **Boundary**: Executed *after* deterministic classification. Cannot alter primary classifications (`EXACT_MATCH`, `PARTIAL_MATCH`, `DISCREPANCY`, `UNMATCHED`) or recalculate financial values.

---

## 3. Fallback & Audit Safety

- **Deterministic Fallback**: If the AI Gateway service is disabled, unreachable, or returns invalid JSON, the application falls back safely to deterministic rules without interrupting the reconciliation pipeline.
- **Confidence Alignment**: AI confidence score is an analytical evidence indicator, NOT a replacement for deterministic Decision Matrix rules.
